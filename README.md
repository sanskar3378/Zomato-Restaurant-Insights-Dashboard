# Zomato Case Study - Solution

1. Download the dataset: https://media.geeksforgeeks.org/wp-content/uploads/20250117023324808265/Zomato-data-.csv
   and save it as `Zomato-data-.csv` next to these files.
2. `pip install pandas numpy matplotlib seaborn scipy streamlit plotly`
3. `python zomato_solution.py Zomato-data-.csv`  -> answers Q1-Q19 + charts in ./output
4. `streamlit run dashboard.py`                  -> the 3-page interactive dashboard
